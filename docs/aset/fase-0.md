# Daftar Aset Fase 0 (0B dan 0C)

Cara pakai: cari aset di sumber yang disarankan dengan kata kunci di bawah, masukkan ke folder tujuan, lalu catat lisensinya di `docs/aset/KREDIT.md`. Jika tidak ketemu dalam waktu wajar, beri tanda ✗ di kolom Status. Claude akan membuat penggantinya (model ProBuilder, tekstur buatan, atau SFX sintetis).

Semua tekstur otomatis diperkecil ke gaya PSX (maks 256 px, filter point), jadi resolusi asli tidak penting. Untuk audio, utamakan format WAV atau OGG.

Sumber: **GF** Google Fonts · **FS** Freesound · **PX** Pixabay (audio) · **PH** Poly Haven · **AC** ambientCG
