# Fase 5: Malam 5 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Malam 5 (Tanah Merah, Malam Minggu Pon) bisa dimainkan penuh dari akhir Malam 4 sampai kartu Malam 6, lewat lima scene: `Scene_RumahKeluarga` (pohon asem di pekarangan belakang: M5 dengan pacul, opsional M6 dengan galah; dialog Laras dua cabang + teh = B4 dan Halaman 6; obat; ritual M5/M6), `Scene_Desa` (gerbang ke makam, rumah Bu Sumi, rumah Pakde), `Scene_Makam` baru (makam Pak Hadi, tiga sampel tanah, panel inspeksi, Pak Lasno = B3), `Scene_RumahBuSumi` (Malam 5: B5 + Halaman 7/B7 jika Kepercayaan ≥ 2, minyak sereh jika 3), dan `Scene_RumahPakde` baru (opsional: anjing penjaga, kunci di pot, laci = B6).

**Architecture (singkat):**
- **Core (aturan baru, TDD):** lima barang baru di `Inventaris` (pacul, galah, teh hangat, sisa makanan, kunci laci); penantian obat Malam 5 di `JamGim.KejadianBerikutnya`; `PetaScene.Makam`/`RumahPakde` + `PetaScene.CatatAsal` (titik muncul di desa dibaca dari `GameState.SceneAsal`, K32-A); kelas baru `KesaksianLaras` (Laras mengunci diri setelah dibentak, terbuka lagi dengan teh, K37-A) + efek dialog `laras-kunci`. **Sudah ada dan dipakai:** `PerbandinganTanah`, `TujuanMalam` (`GaliKendi`, `BandingkanTanah`, `BicaraLaras`), `KepercayaanSumi` (`PintuTerbuka`, `BisaBeriKesaksian`, `BisaBeriMinyakSereh`, `TerimaMinyakSereh`), `BukuHarian` (H7 otomatis B7), `PapanBukti` (K4 menjadi Bukti setelah B6), `MediaSantet` (M5, M6), `RitualPenangkal.MediaBerikutnya`, `PerilakuSantet` (dipakai ulang untuk anjing, K33-A).
- **Runtime:** komponen `PakaiAlat` (interaksi yang butuh barang lalu memutar dialog; untuk pacul, galah, pot, laci) dan `PanelTanah` (inspeksi tiga baris, menjeda); sutradara `AlurMalam5` (rumah), `AlurDesaMalam5` (gerbang-gerbang desa), `AlurMakam`, `AlurRumahPakde`; `AlurRumahBuSumi` diperluas untuk Malam 5; `AlurMalam4` menyerahkan ke Malam 5 + tindak lanjut review Fase 4.
- **Editor (scene dibuat skrip):** `PembuatDataFase5` (dialog + Jurnal Halaman 6/7, Catatan Bapak tanah makam), `PembuatMalam5` (isi Malam 5 di rumah keluarga), `PembuatMakam` dan `PembuatRumahPakde` (scene baru, indeks build 5 dan 6), perluasan `PembuatDesa` dan `PembuatRumahBuSumi`, prefab/suara pengganti, konversi `indonesia-grave`, "Bangun Ulang Semua".

**Tech Stack:** Unity 6000.6.4f1, URP 17.6, Timeline 6.6.0, AI Navigation 2.0.14, ProBuilder 6.1.2. Target build final hanya Windows (Mono); tes harian Play Mode di Mac.

> **Catatan bentuk rencana (dibaca pengeksekusi).** Sama dengan Fase 4: Task Core (Task 2) berisi **kode lengkap + test**. Task Runtime dan Editor (Task 3–11) ditulis pada tingkat **antarmuka + langkah + perintah verifikasi**: nama kelas, `SerializeField`, tanda tangan metode, urutan langkah, dan commit disebut persis, dengan file Fase 3/4 yang ditiru dirujuk per langkah. namespace TheSending.Core
{
    // Game Story Malam 5: dibentak, Laras menangis dan mengunci diri. Raka bisa mencoba lagi setelah membawakan teh hangat.
    public static class KesaksianLaras
    {
        public static void Bentak(GameState s)
        {
            if (s.LarasMengunciDiri) return;
            s.LarasMengunciDiri = true;
            s.Umumkan(Perubahan.Tujuan);
        }

        public static bool BisaBicara(GameState s) => !s.LarasMengunciDiri || Inventaris.Punya(s, Inventaris.TehHangat);

        // true jika teh diberikan: teh habis dan Laras membuka pintu.
        public static bool BeriTeh(GameState s)
        {
            if (!s.LarasMengunciDiri || !Inventaris.Punya(s, Inventaris.TehHangat)) return false;
            s.Barang.Remove(Inventaris.TehHangat);
            s.LarasMengunciDiri = false;
            s.Umumkan(Perubahan.Barang);
            return true;
        }
    }
}
