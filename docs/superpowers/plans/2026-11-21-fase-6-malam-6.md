# Fase 6: Malam 6 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Ledger kemajuan: `.superpowers/sdd/progress.md` (satu baris per task: nomor, status, commit, catatan).

**Goal:** Malam 6 (Obor, Malam Senin Wage) bisa dimainkan penuh dari akhir Malam 5 sampai kartu Malam 7: kartu pembuka, Ibu kerasukan, persiapan sampai 21.00 (Papan Bukti, rumah Pakde jika belum, M6 jika belum, obat 20.00–21.00), Laras berlari masuk pukul 21.00, warga membawa obor ke rumah Bu Sumi di `Scene_Desa`, Sidang Warga (tiga tuduhan, panel bukti, "Diam saja", "Ikut menuduh"), cabang berhasil (Pak Joko menghentikan warga, Bu Sumi bergabung) dan cabang gagal (rumah Bu Sumi terbakar, jalur Fitnah terkunci), lalu pergantian ke Malam 7 dengan `HasilSidang` tersimpan.

**Architecture (singkat):**
- **Core (aturan baru, TDD):** `JamGim.DetikPerJamGim(malam)` (Malam 6 berjalan dengan laju lama, K41-A) dan penantian kursi Malam 6 (`KejadianBerikutnya`: 20.00 lalu 21.00); `SidangWarga.SaatnyaSidang`; kelas instans baru `JalannyaSidang` (urutan tiga tuduhan, hitung benar, Diam/Menuduh langsung gagal, menandai tujuan `SidangWarga` hanya setelah hasil ditetapkan, daftar pilihan jawaban dari Papan Bukti); `TujuanMalam.Teks/BarisHud` Malam 6. **Sudah ada dan dipakai:** `SidangWarga.JawabanBenar/Selesaikan/Diam/IkutMenuduh`, `ItemPapan`, `GameState.JalurFitnah`, `KondisiIbu.MinJalurFitnah`, `JamGim.Batas/BatasKerasTercapai/MulaiJendelaObat(6)`, `PenentuEnding`, `PergantianMalam.Lanjut`, `PetaScene.CatatAsal`.
- **Runtime:** `PanelSidang` (panel yang menjeda: tuduhan + daftar item + "Diam saja" + "Ikut menuduh"), `PemanggilSidang` (di makam, rumah Pakde, rumah Bu Sumi: membawa Raka ke sidang pukul 21.00), `ApiBerkedip` (obor dan api), `PuingRumahSumi` (rumah utuh atau puing menurut `JalurFitnah`), baris hitung mundur 21.00 di `Hud`, `JadwalObat` tanpa teguran di Malam 6; sutradara `AlurMalam6` (rumah) dan `AlurDesaMalam6` (sidang); `AlurDesaMalam5` dan `AlurRumahPakde` ikut Malam 6 (K35-A, CL); `AlurMalam5.GantiMalam` memuat Malam 6.
- **Editor (scene dibuat skrip):** tokoh warga baru di `PembuatPengganti.Tokoh` (pola PSX), prefab obor/api/asap/puing/kaca gelap, suara sintetis; `PembuatDataFase6` (dialog sidang, kerasukan, Laras, Catatan Raka Pasal 252); `PembuatMalam6` (rumah keluarga); `PembuatDesa.Malam6` (kerumunan, sidang, Timeline obor/berhasil/gagal, api, puing, jendela kaca gelap); `PemanggilSidang` dipasang di `PembuatMakam`, `PembuatRumahPakde`, `PembuatRumahBuSumi`; skrip `tools/bangun-semua.sh` dan pemulihan otomatis `ProjectSettings.asset` (K48-A).

**Tech Stack:** Unity 6000.6.4f1, URP 17.6, Timeline 6.6.0, AI Navigation 2.0.14, ProBuilder 6.1.2. Target build final hanya Windows (Mono); tes harian Play Mode di Mac.

> **Catatan bentuk rencana (dibaca pengeksekusi).** Sama dengan Fase 4–5: Task Core (Task 3) dan skrip shell (Task 2) berisi **kode lengkap + test**. Task Runtime dan Editor (Task 4–10) ditulis pada tingkat **antarmuka + langkah + perintah verifikasi**: nama kelas, `SerializeField`, tanda tangan metode, urutan langkah, dan commit disebut persis, dengan file Fase 3–5 yang ditiru dirujuk per langkah. # Menjalankan EditMode test The Sending lewat command line. Editor Unity harus tertutup.
# Pemakaian: bash tools/run-editmode-tests.sh [testFilter]
# Batchmode menghapus define SENTIS_ANALYTICS_ENABLED dari ProjectSettings.asset; skrip ini memulihkannya

#!/usr/bin/env bash
# Menjalankan satu metode editor lewat batchmode (bawaan: "Bangun Ulang Semua"). Editor Unity harus tertutup.
# Pemakaian: bash tools/bangun-semua.sh [Namespace.Kelas.Metode]
# Gagal (exit 1) jika Unity gagal atau log berisi "error CS"/"Exception". ProjectSettings.asset dipulihkan
# jika file itu bersih sebelum Unity dijalankan.
set -euo pipefail
UNITY="/Applications/Unity/Hub/Editor/6000.6.4f1/Unity.app/Contents/MacOS/Unity"
PROJECT="$(cd "$(dirname "$0")/.." && pwd)"
METODE="${1:-TheSending.EditorTools.PembuatMenuUtama.BangunSemua}"
LOG="${TMPDIR:-/tmp}/the-sending-batch.log"
PS="ProjectSettings/ProjectSettings.asset"

bersih=0
git -C "$PROJECT" diff --quiet -- "$PS" && bersih=1

set +e
"$UNITY" -batchmode -quit -projectPath "$PROJECT" -executeMethod "$METODE" -logFile "$LOG"
code=$?
set -e

if [ "$bersih" = 1 ]; then git -C "$PROJECT" checkout -- "$PS"; fi

if [ "$code" != 0 ] || grep -qE 'error CS|Exception' "$LOG"; then
  echo "GAGAL: $METODE (exit $code). Log: $LOG"
  grep -E 'error CS|Exception|another Unity instance' "$LOG" | sort -u | head -20 || true
  exit 1
fi
echo "OK: $METODE"

using System.Collections.Generic;

namespace TheSending.Core
{
    // Urutan Sidang Warga (desain 4.8, Game Story Malam 6): tiga tuduhan berurutan, satu item Papan Bukti per tuduhan.
    // "Diam saja" atau "Ikut menuduh" kapan pun langsung gagal. Tujuan SidangWarga ditandai hanya setelah hasil ditetapkan.
    // Instans per sidang, tidak disimpan (R7): keluar di tengah sidang = ulang dari checkpoint 21.00.
    public sealed class JalannyaSidang
    {
        readonly GameState s;

        public int Tuduhan { get; private set; }
        public int Benar { get; private set; }
        public bool Selesai => s.HasilSidang != HasilSidang.Belum;

        public JalannyaSidang(GameState s)
        {
            this.s = s ?? throw new ArgumentNullException(nameof(s));
            if (Selesai) throw new InvalidOperationException("Sidang Warga sudah selesai.");
        }

        // true jika jawaban untuk tuduhan saat ini benar. Tuduhan ketiga menetapkan hasil.
        public bool Jawab(ItemPapan item)
        {
            if (Selesai) throw new InvalidOperationException("Sidang Warga sudah selesai.");
            bool benar = SidangWarga.JawabanBenar(s, Tuduhan, item);
            if (benar) Benar++;
            Tuduhan++;
            if (Tuduhan == SidangWarga.JumlahTuduhan)
            {
                SidangWarga.Selesaikan(s, Benar);
                TujuanMalam.Selesaikan(s, TujuanMalam.SidangWarga);
            }
            return benar;
        }

        public void Diam()
        {
            SidangWarga.Diam(s);
            TujuanMalam.Selesaikan(s, TujuanMalam.SidangWarga);
        }

        public void IkutMenuduh()
        {
            SidangWarga.IkutMenuduh(s);
            TujuanMalam.Selesaikan(s, TujuanMalam.SidangWarga);
        }

        // Isi panel sidang: Bukti Kunci yang dimiliki (urut B1..B8), lalu Katanya yang diketahui (urut K1..K4).
        public static List<ItemPapan> PilihanJawaban(GameState s)
        {
            var daftar = new List<ItemPapan>();
            for (int b = 0; b < Kode.JumlahBukti; b++)
                if (s.BuktiKunci[b]) daftar.Add(ItemPapan.Bukti(b));
            for (int k = 0; k < Kode.JumlahKatanya; k++)
                if (s.KatanyaDiketahui[k]) daftar.Add(ItemPapan.Katanya(k));
            return daftar;
        }
    }
}
