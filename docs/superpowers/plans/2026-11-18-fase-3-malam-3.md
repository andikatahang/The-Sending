# Fase 3: Malam 3 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Malam 3 ("Tujuh Paku di Saka") bisa dimainkan dari akhir Malam 2 sampai kartu Malam 4. Isinya: Pakde Darmo datang membujuk menjual tanah (Katanya K4), Halaman 3 di kotak sepatu (Bukti B1), Ibu menjerit setiap jam berdentang, kompas ke saka guru, mengetuk saka, tujuh paku (M2) yang dicabut berurutan mulai Jumat dengan tang dari gudang dan Halaman 4, salah urutan memunculkan Sosok Santet, jalan malam lewat desa ke rumah Bu Sumi, sistem Kepercayaan di dalam rumahnya (minta maaf, membantu teplok dan air, menuduh), cerita tiga tahun lalu dan Ritual Penangkal, lalu tutorial Ritual Penangkal dengan benda-benda di dapur dan mengubur abu di pekarangan. Catatan "Fase 3" di `CLAUDE.md` ikut diselesaikan.

**Architecture:** Aturan baru masuk Core dengan TDD: barang `Tang`, tujuan `PakdeDatang` dan `RitualPertama`, puzzle saka dan tujuh paku (`TujuhPaku`, kemajuan tersimpan di `GameState.PakuDicabut`), syarat paku bisa dinetralkan dan media berikutnya untuk anglo (`RitualPenangkal.MediaBerikutnya`), dentang tiap jam dan penantian obat Malam 3 (`JamGim`), nama scene rumah Bu Sumi dan titik muncul di desa (`PetaScene`). `KepercayaanSumi`, `RitualPenangkal`, `MediaSantet`, `BukuHarian`, dan kode efek dialog (`kepercayaan:`, `tuduh-sumi`, `ritual-dari-sumi`, `katanya:`, `halaman:`) sudah ada dan dipakai apa adanya. Runtime tetap tipis: komponen kecil (`KetukSaka`, `PakuDiSaka`, `AmbilBahan`, `RitualDapur`, `BendaRitual`, `KuburAbu`, `Guncang`) dan tiga sutradara: `AlurMalam3` (rumah keluarga), `AlurDesaMalam3` (jalan desa malam di `Scene_Desa`), dan `AlurRumahBuSumi` (interior, scene baru). Isi Malam 3 dipasang ke `Scene_RumahKeluarga` oleh skrip editor baru `PembuatMalam3`; `Scene_RumahBuSumi` dibuat `PembuatRumahBuSumi`; `PembuatDesa` menambah sutradara Malam 3 dan pintu rumah Bu Sumi. Checkpoint hanya di rumah keluarga. Sosok Santet dan lemari Malam 2 dipakai ulang. Tidak ada Timeline baru (adegan Malam 3 pendek, cukup coroutine). Percakapan teks saja.

**Tech Stack:** Unity 6000.6.4f1, URP 17.6, Input System, uGUI 2.6 (legacy `Text`), C# .NET Standard 2.1, Unity Test Framework 1.8.0, modul AI bawaan (`NavMeshAgent`), `bsdtar` bawaan macOS (hanya untuk mengekstrak arsip `old-sofas`, Task 9).

## Global Constraints

- Unity **6000.6.4f1**, URP 17.6. Target build final **hanya Windows** (Mono). Pengembangan dan tes harian di Mac.
- Core: `Assets/_Project/Scripts/Core`, namespace `TheSending.Core`, **tanpa MonoBehaviour**, TDD (test dulu). Runtime: `Assets/_Project/Scripts/Runtime`, namespace `TheSending.Runtime`. Editor: `Assets/_Project/Scripts/Editor`, namespace `TheSending.EditorTools`. Test: `Assets/_Project/Tests/EditMode`, namespace `TheSending.Tests`.

- Hanya satu singleton: `GameManager`. **Tidak ada field `static` baru di Runtime** (`Guncang` adalah kelas static tanpa field). Perpindahan antar-scene tidak membawa data lewat field static: titik muncul dibaca dari `GameState` (`PetaScene.DiDepanRumahBuSumi`, `TujuanMalam`). Gerak di adegan memakai `Time.unscaledDeltaTime`. **Jangan memakai `WaitForSeconds`.** Panel yang menjeda melepasnya tepat sekali, termasuk di `OnDisable`. Jam gim hanya maju saat pemain dikendalikan (juga di desa dan di rumah Bu Sumi).

```csharp
using System;

namespace TheSending.Core
{
    public enum HasilCabut { Ditolak, Benar, Salah }

    // Malam 3 (Game Story): mengetuk empat saka guru, lalu mencabut tujuh paku berukir nama hari dari saka yang benar.
    // Urutan mulai hari malam ini (Kamis malam = malam Jumat), lalu hari-hari berikutnya. Salah urutan: Kondisi Ibu -5,
    // kemajuan tetap; Sosok Santet yang muncul diurus Runtime. Kemajuan disimpan di GameState supaya selamat dari checkpoint.
    public static class TujuhPaku
    {
        public const int Jumlah = 7;
        public const int SakaBenar = 3;   // saka timur laut ruang tengah; nomor saka 0..3 dipasang PembuatMalam3
        public const int MalamPaku = 3;

        static Hari[] Urutan => KalenderJawa.UrutanPaku(MalamPaku);

        // true = saka berbunyi berongga; paku di baliknya ditemukan (M2 otomatis masuk Papan Bukti, desain 4.7).
        public static bool Ketuk(GameState s, int saka)
        {
            if (saka < 0 || saka > 3) throw new ArgumentOutOfRangeException(nameof(saka), saka, "Saka guru harus 0..3.");
            if (saka != SakaBenar) return false;
            MediaSantet.Temukan(s, Kode.M2);
            return true;
        }

        public static bool Selesai(GameState s) => s.PakuDicabut >= Jumlah;

        public static bool SudahDicabut(GameState s, Hari hari) => Array.IndexOf(Urutan, hari) < s.PakuDicabut;

        public static HasilCabut Cabut(GameState s, Hari hari)
        {
            if (!s.MediaDitemukan[Kode.M2] || Selesai(s) || SudahDicabut(s, hari)) return HasilCabut.Ditolak;
            if (Urutan[s.PakuDicabut] != hari)
            {
                KondisiIbu.Ubah(s, KondisiIbu.SalahUrutanPaku);
                return HasilCabut.Salah;
            }
            s.PakuDicabut++;
            if (Selesai(s)) TujuanMalam.Selesaikan(s, TujuanMalam.CabutPaku);
            return HasilCabut.Benar;
        }
    }
```

```csharp
        {
            "boneka kain", "tujuh paku", "bungkusan rambut", "telur ayam cemani", "kendi tanah merah", "kain kafan rajah", "kendi induk",
        };

        {

            {
                ritual = null;
                Media = -1;
                hud.Tampilkan("Ritual gagal: urutannya salah. Media diangkat dari anglo; ulangi dari awal.");
                return;
            }
            hud.Tampilkan(PesanLangkah[ritual.Kemajuan - 1]);
        }

        bool Mulai(GameState s, LangkahRitual langkah)
        {
            if (!s.RitualDiketahui) hud.Tampilkan("Raka belum tahu cara menetralkan media santet.");
            else if (!RitualPenangkal.BahanLengkap(s)) hud.Tampilkan("Bahan ritual belum lengkap: garam, daun kelor, dan bilah bambu kuning.");

            else
            {
                Media = RitualPenangkal.MediaBerikutnya(s);
                ritual = new RitualPenangkal(s, Media);
                return true;
            }
            return false;
        }

            ritual = null;
            Media = -1;
            return true;

            if (api.activeSelf == nyala) return;
            api.SetActive(nyala);
            if (nyala) suaraApi.Putar();
            else suaraApi.Hentikan();
        }
    }
```

```csharp
    // Guncangan pengganti animasi tokoh (Laras gemetar, Ibu menjerit) sampai model beranimasi datang.
    // Waktu tanpa skala, karena adegan menjeda gim.
    public static class Guncang
    {
        public static IEnumerator Posisi(Transform t, float lama, float kuat)
        {
            var awal = t.localPosition;
            for (float w = 0f; w < lama; w += Time.unscaledDeltaTime)
            {
                t.localPosition = awal + new Vector3(Random.Range(-kuat, kuat), 0f, Random.Range(-kuat, kuat));
                yield return null;
            }
            t.localPosition = awal;
        }
    }
}
```

```csharp
            // K21-A: checkpoint sesudah penalti dan sebelum Sosok muncul (desain 2.6), supaya penalti dan paku yang sudah
            // dicabut tidak hilang saat tertangkap.
            gm.SimpanCheckpoint();
            if (!sosokBerjalan) SosokMuncul();
        }

        void SosokMuncul()
        {
            sosokBerjalan = true;
            sisaSosok = LamaSosok;
            suaraStinger.Putar();
            sosok.transform.SetPositionAndRotation(titikMunculSosok.position, titikMunculSosok.rotation);
            sosok.gameObject.SetActive(true);   // SosokSantet.OnEnable menaruhnya di NavMesh dan mulai berpatroli
            musikTegang.Putar();
            hud.Tampilkan("Gemerincing paku terdengar dari dapur. Bersembunyi (E di lemari) dan tahan napas (Spasi).");
        }

        // Sosok pergi setelah LamaSosok detik waktu gim (berhenti saat jeda). Detak jantung selama Raka bersembunyi.
        void AturSosok()
        {
            if (pemain.Bersembunyi != detakBerbunyi)
            {
                detakBerbunyi = pemain.Bersembunyi;
                if (detakBerbunyi) suaraDetak.Putar();
                else suaraDetak.Hentikan();
            }
            sisaSosok -= Time.deltaTime;
            if (sisaSosok > 0f) return;
            sosokBerjalan = false;
            sosok.gameObject.SetActive(false);
            musikTegang.Hentikan();
            suaraDetak.Hentikan();
            detakBerbunyi = false;
            hud.Tampilkan("Gemerincing paku itu menjauh, lalu hilang.");
        }

        void SaatTertangkap()
        {
            if (!sosokBerjalan) return;
            sosokBerjalan = false;
            StartCoroutine(Tertangkap());
        }

        // Desain 4.2: muat checkpoint (salah cabut terakhir, K21-A), lalu Kondisi Ibu -5. Scene dimuat ulang dari state itu.
        IEnumerator Tertangkap()
        {
            sibuk = true;
            var gm = GameManager.Instance;
            adegan.Mulai();
            musikTegang.Hentikan();
            suaraDetak.Hentikan();
            suaraStinger.Putar();
            yield return kartu.StartCoroutine(kartu.Tampilkan("", "Sosok itu menemukan Raka.", 2f));
            yield return kartu.StartCoroutine(kartu.KeHitam());
            gm.Tertangkap();
            // Jeda dilepas KameraAdegan.OnDisable saat scene dibongkar.
            gm.MuatScene(gm.State.Ending != Ending.Belum ? GameManager.SceneMenuUtama : gm.SceneUntukState);
        }

        // Game Story Malam 3 butir 7: Raka pergi ke rumah Bu Sumi (K17-B: berjalan lewat Scene_Desa).
        void SaatPintuDepan()
        {
            if (!berjalan || sibuk) return;
            var s = State;
            if (!TujuanMalam.Sudah(s, TujuanMalam.CabutPaku))
                hud.Tampilkan("Raka tidak bisa pergi selama Ibu terus menjerit.");
            else if (TujuanMalam.Sudah(s, TujuanMalam.KunjungiSumi))
                hud.Tampilkan("Sudah larut. Raka tidak keluar lagi malam ini.");
            else if (sosokBerjalan)
                hud.Tampilkan("Gemerincing paku masih terdengar. Jangan keluar sekarang.");
            else
                StartCoroutine(KeRumahBuSumi());
        }

        IEnumerator KeRumahBuSumi()
        {
            sibuk = true;
            adegan.Mulai();
            suaraPintuDepan.Putar();
            yield return kartu.StartCoroutine(kartu.KeHitam());
            GameManager.Instance.MuatScene(PetaScene.Desa);   // AlurDesaMalam3 menaruh Raka di depan rumah keluarga
        }

        // Ending sebelum Fase 7: kembali ke menu utama (layar ending dibuat di Fase 7).
        bool KeMenuJikaEnding(GameManager gm)
        {
            if (gm.State.Ending == Ending.Belum) return false;
            Debug.LogWarning("Ending tercapai di Malam 3; layar ending dibuat di Fase 7.", this);
            gm.MuatScene(GameManager.SceneMenuUtama);
            return true;
        }

        IEnumerator GantiMalam(GameState s)
        {
            gantiDimulai = true;
            sibuk = true;
            var gm = GameManager.Instance;
            bool dimuat = false;
            adegan.Mulai();
            try
            {
                yield return kartu.StartCoroutine(kartu.KeHitam());
                PergantianMalam.Lanjut(s);        // Malam 4, Kondisi Ibu -12
                if (KeMenuJikaEnding(gm))         // catatan 0B: -12 bisa langsung memicu ending
                {
                    dimuat = true;
                    yield break;
                }
                gm.SimpanCheckpoint();            // checkpoint awal Malam 4
                // Fase 4 mengganti bagian di bawah ini dengan gm.MuatScene(gm.SceneUntukState) untuk sutradara Malam 4.
                yield return kartu.StartCoroutine(kartu.Tampilkan(
                    "Malam 4: Rambut di Dasar Sumur",
                    KalenderJawa.NamaMalam(4) + "\n\n" + RingkasanMalam4 + "\n\n(Bersambung. Malam 4 dibuat di Fase 4.)", 8f));
                yield return kartu.StartCoroutine(kartu.KeHitam());
                gm.MuatScene(GameManager.SceneMenuUtama);
                dimuat = true;
            }
            finally { if (!dimuat) adegan.Selesai(); }   // jeda dilepas KameraAdegan.OnDisable saat scene dibongkar
        }
    }
}
```

```csharp
using System;
using System.Collections;
using TheSending.Core;
using UnityEngine;

namespace TheSending.Runtime
{
    // Sutradara interior rumah Bu Sumi pada Malam 3 (Game Story Malam 3 butir 7-8, Kepercayaan 6.4, K17-B dan K23-A).
    // Bu Sumi dingin di depan pintu; pilihan dialog: minta maaf (+1), menuduh (-1, Raka diusir dan pintu ditutup sampai
    // malam berikutnya), atau menawarkan bantuan. Teplok di meja dan sumur di halaman belakang (+1 setelah keduanya, lapor
    // ke Bu Sumi). Kepercayaan minimal 1: cerita tiga tahun lalu dan Ritual Penangkal di bale-bale. Pintu keluar ke desa.
    // Tidak ada checkpoint di sini; kemajuan kunjungan disimpan di GameState lewat efek dialog.
    public class AlurRumahBuSumi : MonoBehaviour
    {
        const float LamaKerja = 2.5f;

        [SerializeField] KameraAdegan adegan;
        [SerializeField] KartuTeks kartu;
        [SerializeField] PanelDialog dialog;
        [SerializeField] Hud hud;
        [SerializeField] PemainGerak pemain;
        [SerializeField] DataDialog dialogPintu, dialogMenunggu, dialogTerimaKasih, dialogPamit, dialogCerita;
        [SerializeField] InteraktifAlur buSumi, teplok, sumur, pintuKeluar;
        [SerializeField] GameObject cahayaTeplok;
        [SerializeField] Transform titikMulai, titikBale, titikSumiBale, bidikBale;
        [SerializeField] Suara suaraBanting, suaraTimba, suaraPintu;

        bool berjalan, sibuk, teplokBeres, airBeres, ceritaSudah, peringatanPulang;

        static GameState State => GameManager.Instance.State;

        void OnEnable()
        {
            buSumi.Ditekan += SaatBuSumi;
            teplok.Ditekan += SaatTeplok;
            sumur.Ditekan += SaatSumur;
            pintuKeluar.Ditekan += SaatKeluar;
        }

        void OnDisable()
        {
            buSumi.Ditekan -= SaatBuSumi;
            teplok.Ditekan -= SaatTeplok;
            sumur.Ditekan -= SaatSumur;
            pintuKeluar.Ditekan -= SaatKeluar;
        }

        void Start()
        {
            var gm = GameManager.Instance;
            if (gm == null)
            {
                Debug.LogError("AlurRumahBuSumi butuh GameManager di scene.", this);
                enabled = false;
                return;
            }
            var s = gm.State;
            kartu.HitamSeketika();
            pemain.Pindah(titikMulai);
            cahayaTeplok.SetActive(false);
            if (s.MalamKe != 3)
            {
                // Isi Malam 4 ke atas dibuat di fase berikutnya; pintu keluar tetap bisa dipakai.
                hud.Tampilkan("Rumah Bu Sumi pada malam ini belum dibuat.");
                kartu.StartCoroutine(kartu.DariHitam());
                return;
            }
            berjalan = true;
            // Kepercayaan >= 1 dan bahan lengkap berarti cerita sudah didengar (hanya terjadi lewat save uji F5).
            ceritaSudah = KepercayaanSumi.BisaAjarkanRitual(s) && RitualPenangkal.BahanLengkap(s);
            StartCoroutine(Datang());
        }

        IEnumerator Datang()
        {
            sibuk = true;
            yield return kartu.StartCoroutine(kartu.DariHitam());
            hud.Tampilkan("Bu Sumi membukakan pintu dan berdiri menghalangi. Dapurnya gelap; teploknya mati.");
            sibuk = false;
        }

        void SaatBuSumi()
        {
            if (!berjalan || sibuk) return;
            var s = State;
            DataDialog d;
            if (!TujuanMalam.Sudah(s, TujuanMalam.KunjungiSumi)) d = dialogPintu;
            else if (s.AksiSumiDipakai[(int)AksiSumi.BantuLampuDanAir]) d = dialogPamit;
            else if (teplokBeres && airBeres) d = dialogTerimaKasih;
            else d = dialogMenunggu;
            StartCoroutine(Bicara(d));
        }

        IEnumerator Bicara(DataDialog d)
        {
            sibuk = true;
            yield return dialog.MulaiDanTunggu(d);
            var s = State;
            if (!KepercayaanSumi.PintuTerbuka(s))
            {
                // Game Story 6.4: menuduh langsung = -1 dan pintu ditutup sampai malam berikutnya. Raka diusir ke jalan.
                yield return Keluar(suaraBanting);
                yield break;
            }
            if (KepercayaanSumi.BisaAjarkanRitual(s) && !ceritaSudah) yield return Cerita();
            sibuk = false;
        }

        // Game Story Malam 3 butir 8: Kepercayaan minimal 1, Bu Sumi bercerita dan mengajarkan Ritual Penangkal.
        IEnumerator Cerita()
        {
            ceritaSudah = true;
            adegan.Mulai();
            try
            {
                yield return kartu.StartCoroutine(kartu.KeHitam());
                pemain.Pindah(titikBale);
                buSumi.transform.SetPositionAndRotation(titikSumiBale.position, titikSumiBale.rotation);
                adegan.Bidik(bidikBale);
                yield return kartu.StartCoroutine(kartu.DariHitam());
                yield return dialog.MulaiDanTunggu(dialogCerita);   // efek ritual-dari-sumi: pengetahuan + satu ikat bahan
            }
            finally { adegan.Selesai(); }
            hud.Tampilkan("Bu Sumi memberi seikat garam, daun kelor, dan bilah bambu kuning.");
            hud.Tampilkan("Media santet dinetralkan di anglo dapur rumah.");
        }

        void SaatTeplok() => Bantu(teplokBeres, "Raka membersihkan sumbu dan menuang minyak. Teplok menyala lagi.", () =>
        {
            teplokBeres = true;
            cahayaTeplok.SetActive(true);
            teplok.UbahPrompt("Teplok sudah menyala");
        });

        void SaatSumur() => Bantu(airBeres, "Raka menimba air dan mengisi gentong Bu Sumi sampai penuh.", () =>
        {
            airBeres = true;
            suaraTimba.Putar();
            sumur.UbahPrompt("Gentong sudah penuh");
        });

        // K23-A: dua pekerjaan sederhana; Kepercayaan +1 diberikan dialog terima kasih setelah keduanya selesai.
        void Bantu(bool sudah, string teks, Action selesai)
        {
            if (!berjalan || sibuk || sudah) return;
            var s = State;
            if (!TujuanMalam.Sudah(s, TujuanMalam.KunjungiSumi))
                hud.Tampilkan("Raka belum bicara dengan Bu Sumi.");
            else if (!s.AksiSumiDipakai[(int)AksiSumi.BantuLampuDanAir])
                StartCoroutine(Kerja(teks, selesai));
        }

        IEnumerator Kerja(string teks, Action selesai)
        {
            sibuk = true;
            yield return kartu.StartCoroutine(kartu.Tampilkan("", teks, LamaKerja));
            selesai();
            if (teplokBeres && airBeres) hud.Tampilkan("Beri tahu Bu Sumi.");
            sibuk = false;
        }

        // R4: kunjungan sekali per malam. Keluar sebelum selesai membantu diberi peringatan satu kali.
        void SaatKeluar()
        {
            if (sibuk) return;
            if (berjalan)
            {
                var s = State;
                if (!TujuanMalam.Sudah(s, TujuanMalam.KunjungiSumi))
                {
                    hud.Tampilkan("Raka belum bicara dengan Bu Sumi.");
                    return;
                }
                if (!s.AksiSumiDipakai[(int)AksiSumi.BantuLampuDanAir] && !peringatanPulang)
                {
                    peringatanPulang = true;
                    hud.Tampilkan("Bu Sumi masih butuh bantuan (teplok, air). Raka tidak kembali lagi malam ini. Tekan E sekali lagi untuk keluar.");
                    return;
```

```csharp
using System.IO;
using TheSending.Core;
using TheSending.Runtime;
using UnityEditor;
using UnityEditor.SceneManagement;
using UnityEngine;
using static TheSending.EditorTools.PembuatRig;
using static TheSending.EditorTools.PembuatSandbox;

namespace TheSending.EditorTools
{
    // Membuat Scene_RumahBuSumi (K17-B): interior dapur jamu dan halaman belakang kecil dengan sumur. Dimuat dari pintu
    // rumah Bu Sumi di Scene_Desa pada Malam 3. Jangan sunting scene dengan tangan; ubah angka di sini lalu bangun ulang.
    // Batchmode: Unity -batchmode -quit -projectPath <proyek> -executeMethod TheSending.EditorTools.PembuatRumahBuSumi.Buat
    public static class PembuatRumahBuSumi
    {
        internal const string JalurScene = "Assets/_Project/Scenes/" + PetaScene.RumahBuSumi + ".unity";
        const float Tinggi = 2.8f, Tebal = 0.15f;
        const string Sfx = PembuatPengganti.FolderSfx;
        const string WarnaBulan = "6D86A8", WarnaTeplok = "FFB46B";

        [MenuItem("The Sending/Buat Scene Rumah Bu Sumi")]
        public static void Buat()
        {
            PembuatPengganti.Buat();
            Directory.CreateDirectory(Path.GetDirectoryName(JalurScene));
            var scene = EditorSceneManager.NewScene(NewSceneSetup.EmptyScene, NewSceneMode.Single);
            PembuatGayaPsx.TerapkanKeScene();
            var rig = PembuatRig.Buat(new Vector3(0f, 0.05f, 0.8f));
            SetAngka(rig.Langkah, "bawaan", (int)JenisPermukaan.Kayu);

            var alur = new GameObject("Sutradara").AddComponent<AlurRumahBuSumi>();
            Set(alur, "adegan", rig.Adegan);
            Set(alur, "kartu", rig.Kartu);
            Set(alur, "dialog", rig.Dialog);
            Set(alur, "hud", rig.Hud);
            Set(alur, "pemain", rig.Pemain);
            Set(alur, "dialogPintu", PembuatDataFase3.Muat(PembuatDataFase3.SumiPintu));
            Set(alur, "dialogMenunggu", PembuatDataFase3.Muat(PembuatDataFase3.SumiMenunggu));
            Set(alur, "dialogTerimaKasih", PembuatDataFase3.Muat(PembuatDataFase3.SumiTerimaKasih));
            Set(alur, "dialogPamit", PembuatDataFase3.Muat(PembuatDataFase3.SumiPamit));
            Set(alur, "dialogCerita", PembuatDataFase3.Muat(PembuatDataFase3.SumiCerita));
            Set(alur, "titikMulai", Titik("TitikMulai", new Vector3(0f, 0.05f, 0.8f), new Vector3(0f, 0.05f, 5f)));

            Ruang(rig, alur);
            HalamanBelakang(rig, alur);

            EditorSceneManager.SaveScene(scene, JalurScene);
            AssetDatabase.SaveAssets();
            Debug.Log($"Scene rumah Bu Sumi dibuat: {JalurScene}");
        }

        // Dinding lurus sejajar sumbu, dari (x1, z1) ke (x2, z2).
        static void Dinding(float x1, float z1, float x2, float z2)
        {
            var ukuran = new Vector3(Mathf.Abs(x2 - x1) + Tebal, Tinggi, Mathf.Abs(z2 - z1) + Tebal);
            Balok("Dinding", new Vector3((x1 + x2) / 2f, Tinggi / 2f, (z1 + z2) / 2f), ukuran, "Gedek");
        }

        // Dapur jamu 8 x 5 m: pintu depan (keluar ke desa), pintu belakang ke halaman, teplok mati, bale-bale, rak, lumpang.
        static void Ruang(Rig rig, AlurRumahBuSumi alur)
        {
            Balok("Lantai", new Vector3(0f, -0.1f, 2.5f), new Vector3(8f, 0.2f, 5f), "KayuTua");
            Balok("Plafon", new Vector3(0f, Tinggi + 0.1f, 2.5f), new Vector3(8f, 0.2f, 5f), "KayuGelap");
            Dinding(-4f, 0f, -0.6f, 0f);
            Dinding(0.6f, 0f, 4f, 0f);
            Balok("AmbangPintuDepan", new Vector3(0f, 2.45f, 0f), new Vector3(1.2f, 0.7f, Tebal), "Gedek");
            Dinding(-4f, 5f, 2f, 5f);
            Dinding(3f, 5f, 4f, 5f);
            Balok("AmbangPintuBelakang", new Vector3(2.5f, 2.45f, 5f), new Vector3(1f, 0.7f, Tebal), "Gedek");
            Dinding(-4f, 0f, -4f, 5f);
            Dinding(4f, 0f, 4f, 5f);
            Balok("PintuDepanTertutup", new Vector3(0f, 1.05f, -0.08f), new Vector3(1.2f, 2.1f, 0.06f), "KayuGelap");   // daun pintu di luar ambang

            var keluar = Logika("PintuKeluar", new Vector3(0f, 0f, 0.1f), new Vector3(1.2f, 2.1f, 0.1f));
            var k = keluar.AddComponent<InteraktifAlur>();
            SetTeks(k, "prompt", "Keluar ke jalan");
            Set(alur, "pintuKeluar", k);
            Set(alur, "suaraPintu", BuatSuara(rig, "PintuBerderit", Sfx, "SFX", "(Suara: pintu kayu berderit.)"));
            Set(alur, "suaraBanting", BuatSuara(rig, "PintuDibanting", Sfx, "SFX", "(Suara: pintu dibanting.)"));

            // Teplok mati di meja: dapur hanya diterangi cahaya redup dari pintu belakang sampai teplok diperbaiki.
            PembuatPengganti.Pasang("Meja", null, new Vector3(-2.5f, 0f, 1.2f));
            var teplok = Logika("TeplokMeja", new Vector3(-2.5f, 0.76f, 1.2f), new Vector3(0.3f, 0.35f, 0.3f));
            PembuatPengganti.Pasang("Teplok", teplok.transform, Vector3.zero);
            var perbaiki = teplok.AddComponent<InteraktifAlur>();
            SetTeks(perbaiki, "prompt", "Perbaiki lampu teplok");
            Set(alur, "teplok", perbaiki);
            var cahaya = Lampu("CahayaTeplok", new Vector3(-2.5f, 1.1f, 1.2f), WarnaTeplok, 7f, 2f);
            Set(alur, "cahayaTeplok", cahaya.gameObject);
            cahaya.gameObject.SetActive(false);
            Lampu("CahayaRedup", new Vector3(1f, 2.4f, 2.5f), WarnaBulan, 6f, 0.5f);

            PembuatPengganti.Pasang("BaleBale", null, new Vector3(-2.4f, 0f, 3.8f));
            PembuatPengganti.Pasang("RakBotol", null, new Vector3(2.6f, 0f, 4.7f), 180f);
            PembuatPengganti.Pasang("Lumpang", null, new Vector3(1.2f, 0f, 2.6f));

            var sumi = Logika("BuSumi", new Vector3(0f, 0f, 2.2f), new Vector3(0.5f, 1.65f, 0.5f));
            PembuatPengganti.Pasang("BuSumi", sumi.transform, Vector3.zero, 180f);
            var bicara = sumi.AddComponent<InteraktifAlur>();
            SetTeks(bicara, "prompt", "Bicara dengan Bu Sumi");
            Set(alur, "buSumi", bicara);

            Set(alur, "titikBale", Titik("TitikBale", new Vector3(-1.4f, 0.05f, 2.8f), new Vector3(-2.4f, 0.05f, 3.8f)));
            Set(alur, "titikSumiBale", Titik("TitikSumiBale", new Vector3(-2.4f, 0f, 4.1f), new Vector3(-1.4f, 0f, 2.8f)));
            Set(alur, "bidikBale", Titik("BidikBale", new Vector3(-0.6f, 1.5f, 1.6f), new Vector3(-2.4f, 1.2f, 4.1f)));
        }

        // Halaman belakang 8 x 6 m berpagar bambu dengan sumur timba, diterangi bulan.
        static void HalamanBelakang(Rig rig, AlurRumahBuSumi alur)
        {
            Balok("Halaman", new Vector3(0f, -0.1f, 8f), new Vector3(8f, 0.2f, 6f), "Tanah")
                .AddComponent<Permukaan>().Jenis = JenisPermukaan.Tanah;
            Batas("Batas", new Vector3(-4.1f, 1.5f, 8f), new Vector3(0.2f, 3f, 6f));
            Batas("Batas", new Vector3(4.1f, 1.5f, 8f), new Vector3(0.2f, 3f, 6f));
            Batas("Batas", new Vector3(0f, 1.5f, 11.1f), new Vector3(8f, 3f, 0.2f));
            foreach (float x in new[] { -3.4f, 0f, 3.4f })
                PembuatPengganti.Pasang("RumpunBambu", null, new Vector3(x, 0f, 10.7f));
            var bulan = new GameObject("Cahaya bulan").AddComponent<Light>();
            bulan.type = LightType.Spot;
            bulan.color = Hex(WarnaBulan);
            bulan.range = 9f;
            bulan.spotAngle = 80f;
            bulan.intensity = 1.3f;
            bulan.transform.SetPositionAndRotation(new Vector3(1f, 6f, 8f), Quaternion.Euler(90f, 0f, 0f));

            var sumur = Logika("Sumur", new Vector3(1.5f, 0f, 8.5f), new Vector3(1.2f, 1f, 1.2f));
            PembuatPengganti.Pasang("Sumur", sumur.transform, Vector3.zero, -90f);
            var timba = sumur.AddComponent<InteraktifAlur>();
            SetTeks(timba, "prompt", "Timba air untuk Bu Sumi");
            Set(alur, "sumur", timba);
            Set(alur, "suaraTimba", BuatSuara(rig, "AirDitimba", Sfx, "SFX", "(Suara: air ditimba dari sumur.)"));
        }
    }
}
```

## Daftar Cek Play Mode Fase 3 (dikerjakan tim)

Prasyarat: Task 12 selesai dan editor dibuka sesudahnya. Tombol uji (editor dan development build): **F5** simpan checkpoint, **F6** jam gim +30 menit, **F9** tertangkap. Bunyi yang filenya belum ada tampil sebagai teks "(Suara: ...)" di HUD; itu dihitung lolos. Percakapan teks saja. Cara cepat ke Malam 3: mainkan Malam 2 sampai selesai, atau "Lanjutkan" dari save yang dibuat setelah kartu Malam 3. Untuk menguji cabang berbeda (minta maaf, menuduh, salah cabut), tekan F5 di rumah keluarga tepat sebelum percabangan lalu "Lanjutkan" (F5 di desa atau rumah Bu Sumi juga dimuat di rumah keluarga). Catat nomor butir yang gagal beserta apa yang terlihat.

**Masuk Malam 3 dan Pakde**

1. Akhir Malam 2 (sampai kamar Raka tanpa tertangkap): layar hitam, rumah dimuat ulang, kartu "Malam 3: Tujuh Paku di Saka" sekitar 8 detik dengan "Malam Jumat Legi", ringkasan siang, dan tujuan. Tidak ada lagi kartu "(Bersambung...)" Malam 3. HUD "Selasa Kliwon: 4 malam lagi"; Kondisi Ibu (teks uji kiri atas) 12 lebih rendah daripada akhir Malam 2.
2. Motor berhenti (bunyi atau teks), ketukan, layar hitam, lalu kamera membidik Pakde Darmo di samping sofa ruang tengah; buah tangan ada di meja. Dialog 7 baris; kutipan "Kamu itu masih anak kecil, Le. Nggak ngerti keadaan. Tanah itu dijual, ibumu bisa berobat, kalian bisa hidup enak." tampil persis. Muncul notifikasi Papan Bukti diperbarui.
3. Setelah dialog: layar hitam, Pakde hilang, motor menjauh, Raka berdiri di kamarnya, dua notifikasi. Jurnal > Papan Bukti menampilkan `[KATANYA] K4` (pembeli tanah). Buah tangan tetap di meja.
4. Sofa di dinding selatan ruang tengah: dudukan menghadap ke tengah ruang, tidak melayang atau tenggelam, tidak menghalangi pintu kamar Raka atau pintu depan. (Jika menghadap dinding: Task 9 Step 2.)

**Halaman 3, jeritan, dan kompas**

5. Kotak sepatu di kamar Raka: "Buka kotak sepatu lama", dialog 2 baris, notifikasi halaman ditemukan dan bukti baru (B1). Jurnal > Buku Harian: Halaman 3 berisi teks. Jurnal > Papan Bukti: B1.
6. Segera setelah dialog kotak sepatu: kamera membidik ranjang Ibu, Ibu berguncang sekitar 2,5 detik, dentang jam dan jeritan (atau teksnya), lalu dua notifikasi (jeritan dan kompas). Terjadi sekali saja.
7. Kompas (C) berputar paling kencang di dekat saka guru timur laut ruang tengah (dekat pintu kamar Laras), lebih pelan di saka lain.
8. Setiap jam penuh (F6 mempercepat) sampai paku ketujuh tercabut: dentang, jeritan, dan notifikasi "Jam berdentang...". Tidak terjadi sebelum kotak sepatu dibuka, dan tidak lagi setelah paku tercabut semua.

**Saka, tang, Halaman 4, dan paku**

9. Ketuk saka (E, "Ketuk saka guru"): tiga saka berbunyi padat dengan notifikasi; saka timur laut berbunyi berongga, dempul hitam hilang, tujuh paku muncul, notifikasi media dan petunjuk ke gudang. Saka tidak bisa diketuk lagi setelah itu.
10. Kalender di dapur: "Kamis. Malam ini malam Jumat Legi."
11. Gudang terbuka sejak awal Malam 3 (tanpa kunci, pintunya tidak ada). Tang di rak alat: "Ambil tang", tang hilang, inventaris (I) bertambah "Tang". Halaman di rak: dialog 2 baris; Jurnal > Buku Harian Halaman 4 berisi aturan mencabut paku dan enam langkah ritual dengan tempat bahannya.
12. Paku tanpa tang: prompt "Paku berukir ...", E memunculkan "Butuh tang." Dengan tang: "Cabut paku berukir ...". Ukiran dari atas ke bawah: Selasa, Jumat, Minggu, Kamis, Sabtu, Rabu, Senin. Paku bisa dibidik satu per satu dari depan saka.
13. Urutan benar Jumat, Sabtu, Minggu, Senin, Selasa, Rabu, Kamis: setiap paku hilang dengan bunyi cabut; setelah paku ketujuh muncul "Jeritan Ibu berhenti" dan petunjuk Bu Sumi. Pintu depan kini berprompt "Pergi ke rumah Bu Sumi".
14. Uji terpisah, salah urutan: paku tidak lepas, Kondisi Ibu turun 5, stinger, Sosok Santet keluar dari dapur, musik tegang, notifikasi bersembunyi. Paku yang sudah dicabut tetap hilang.
15. Selama Sosok ada: lemari pakaian ruang tengah bisa dipakai bersembunyi, detak jantung terdengar, menahan napas bekerja seperti Malam 2. Sekitar 40 detik kemudian Sosok hilang dan muncul "Gemerincing paku itu menjauh". Salah cabut lagi saat Sosok masih ada: Kondisi Ibu −5 lagi, Sosok tidak muncul dua kali.
16. Tertangkap (atau F9 saat Sosok ada): kartu "Sosok itu menemukan Raka.", rumah dimuat ulang dengan Raka di ruang tengah (tanpa kartu Malam 3 panjang dan tanpa Pakde), paku yang sudah dicabut tetap tercabut, Kondisi Ibu 5 lebih rendah daripada saat salah cabut. Stop Play, Play, "Lanjutkan": keadaan sama.
17. Pintu depan sebelum paku ketujuh: "Raka tidak bisa pergi selama Ibu terus menjerit." Saat Sosok masih ada: "Gemerincing paku masih terdengar...".

**Jalan desa malam (K17-B)**

18. E di pintu depan: bunyi pintu, layar hitam, `Scene_Desa` pada malam hari: Raka berdiri di depan emper rumah keluarga menghadap selatan, kabut tebal, lampu jalan menyala, notifikasi arah ke rumah Bu Sumi. Tidak ada mobil, kartu Prolog, azan, atau tutorial senter. Jam terus berjalan.
19. Pintu rumah keluarga di desa sebelum berkunjung: "Raka belum menemui Bu Sumi." Berjalan ke selatan sekitar 25 m: rumah Bu Sumi di kanan jalan, jendelanya menyala. Pintunya berprompt "Ketuk pintu Bu Sumi".
20. Ketuk: bunyi ketukan, layar hitam, `Scene_RumahBuSumi`: Raka di dalam ambang pintu dapur, Bu Sumi berdiri di depannya, dapur gelap (teplok mati), cahaya redup dari pintu belakang. Gaya PSX dan kabut sama.

**Rumah Bu Sumi**

21. Pintu keluar sebelum bicara: "Raka belum bicara dengan Bu Sumi." Teplok dan sumur sebelum bicara: "Raka belum bicara dengan Bu Sumi."
22. Bicara: kalimat Jawa dengan terjemahan miring dalam kurung, lalu tiga pilihan (tombol 1–3).
23. Pilihan 1 (minta maaf): Bu Sumi melunak dan menyebut teplok dan gentong, lalu layar hitam, Raka dan Bu Sumi di bale-bale, dialog cerita 8 baris dengan kutipan "Aku ora tau nyantet sapa-sapa. Aku mung tau nangis." dan "Wong sing teka tanpa diundang, ojo dikei apa-apa." persis, lalu notifikasi bahan.
24. Teplok di meja: "Perbaiki lampu teplok", kartu sekitar 2,5 detik, dapur menjadi terang hangat. Lewat pintu belakang ke halaman: sumur "Timba air untuk Bu Sumi", kartu, bunyi timba. Setelah keduanya: "Beri tahu Bu Sumi." Bicara: terima kasih. Bicara lagi: pamit.
25. Uji terpisah, pilihan 3 (menawarkan bantuan) tanpa minta maaf: teplok dan sumur, lapor ke Bu Sumi, terima kasih, lalu langsung adegan cerita di bale-bale (Kepercayaan 1).
26. Pintu keluar setelah bicara tetapi sebelum membantu: peringatan sekali, E lagi untuk keluar. Keluar: layar hitam, desa, Raka di depan pintu rumah Bu Sumi menghadap jalan, notifikasi arah pulang. Ketuk lagi: "Sudah larut. Bu Sumi tidak membuka pintunya lagi malam ini."
27. Uji terpisah, pilihan 2 (menuduh): Bu Sumi mengusir Raka; bunyi pintu dibanting, layar hitam, desa di depan pintu Bu Sumi, notifikasi pintu dibanting dan Halaman 4.
28. Pintu rumah keluarga di desa setelah berkunjung: layar hitam, rumah keluarga, Raka berdiri di dalam pintu depan, notifikasi keadaan bahan. Pintu depan lagi: "Sudah larut. Raka tidak keluar lagi malam ini." "Lanjutkan" dari menu setelah keluar di tengah jalan desa: rumah keluarga dari checkpoint terakhir (kunjungan hilang jika checkpoint dibuat sebelum berangkat).

**Ritual Penangkal (K25-B)**

Rak bumbu di meja dapur "Ambil garam", pohon kelor di pekarangan belakang "Petik daun kelor", bambu kuning di gudang "Ambil bilah bambu kuning". Sebelum Halaman 4 dibaca, ketiganya tidak berprompt.
