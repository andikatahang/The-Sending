# Fase 3: Malam 3 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Malam 3 ("Tujuh Paku di Saka") bisa dimainkan dari akhir Malam 2 sampai kartu Malam 4. Isinya: Pakde Darmo datang membujuk menjual tanah (Katanya K4), Halaman 3 di kotak sepatu (Bukti B1), Ibu menjerit setiap jam berdentang, kompas ke saka guru, mengetuk saka, tujuh paku (M2) yang dicabut berurutan mulai Jumat dengan tang dari gudang dan Halaman 4, salah urutan memunculkan Sosok Santet, rumah Bu Sumi dengan sistem Kepercayaan (minta maaf, membantu teplok dan air, menuduh), cerita tiga tahun lalu dan Ritual Penangkal, lalu tutorial Ritual Penangkal di anglo dapur dan mengubur abu di pekarangan. Catatan "Fase 3" di `CLAUDE.md` ikut diselesaikan.

**Architecture:** Aturan baru masuk Core dengan TDD: barang `Tang`, tujuan `PakdeDatang` dan `RitualPertama`, puzzle saka dan tujuh paku (`TujuhPaku`, kemajuan tersimpan di `GameState.PakuDicabut`), syarat paku bisa dinetralkan, dentang tiap jam dan penantian obat Malam 3 (`JamGim`), nama scene rumah Bu Sumi (`PetaScene`). `KepercayaanSumi`, `RitualPenangkal`, `MediaSantet`, `BukuHarian`, dan kode efek dialog (`kepercayaan:`, `tuduh-sumi`, `ritual-dari-sumi`, `katanya:`, `halaman:`) sudah ada dan dipakai apa adanya. Runtime tetap tipis: komponen kecil (`KetukSaka`, `PakuDiSaka`, `AmbilBahan`, `PanelRitual`, `AngloRitual`, `KuburAbu`, `Guncang`) dan dua sutradara: `AlurMalam3` (rumah keluarga) dan `AlurRumahBuSumi` (scene baru). Isi Malam 3 dipasang ke `Scene_RumahKeluarga` oleh skrip editor baru `PembuatMalam3`; `Scene_RumahBuSumi` dibuat `PembuatRumahBuSumi`. Sosok Santet dan lemari Malam 2 dipakai ulang. Tidak ada Timeline baru (adegan Malam 3 pendek, cukup coroutine). Percakapan teks saja.

**Tech Stack:** Unity 6000.6.4f1, URP 17.6, Input System, uGUI 2.6 (legacy `Text`), C# .NET Standard 2.1, Unity Test Framework 1.8.0, modul AI bawaan (`NavMeshAgent`), `bsdtar` bawaan macOS (hanya untuk mengekstrak arsip `old-sofas`, Task 9).

## KEPUTUSAN TIM (MENUNGGU JAWABAN TIM)

**K17–K25 belum diputuskan.** Rencana di bawah ditulis untuk **rekomendasi** setiap keputusan. Baris "Jika tim memilih ..." menyebut perubahan yang dibutuhkan untuk pilihan lain. Penomoran meneruskan K1–K16 dari Fase 1 dan 2.

**K17. Perjalanan ke rumah Bu Sumi.**
Game Story Malam 3 butir 7: Raka pergi ke rumah Bu Sumi. GDD menaruh bagian luar rumah Bu Sumi di `Scene_Desa` dan interiornya di `Scene_RumahBuSumi`. `Scene_Desa` hanya punya sutradara Prolog.

- B. Lewat `Scene_Desa` (jalan malam, bagian luar rumah Bu Sumi di desa), interior di `Scene_RumahBuSumi`. Butuh sutradara desa Malam 3, titik masuk baru di desa, dan dua kali pindah scene; sekitar satu hari kerja tambahan.
- **Rekomendasi: A.**
- Jika tim memilih B: controller melapor dulu (butuh task tambahan untuk `Scene_Desa`).

**K18. Pekarangan untuk daun kelor dan mengubur abu.**
Desain 4.5: daun kelor di pohon pekarangan, abu dikubur dengan tangan di pekarangan. Rumah keluarga belum punya area luar (pintu depan tertutup sejak Fase 1).
- **A. Pintu belakang di dinding utara dapur ke pekarangan belakang kecil** (10 × 7 m, pagar bambu, pohon kelor, tanah tempat mengubur abu). Pintu itu tertutup di Malam 1–2. Fase 4 menaruh sumur belakang di sini. Task 11.
- B. Tanpa pekarangan: pohon kelor dan tempat mengubur abu di halaman rumah Bu Sumi. Menyimpang dari desain 4.5, dan pemain yang dimusuhi Bu Sumi tidak bisa mengambil kelor.
- **Rekomendasi: A.**
- Jika tim memilih B: controller melapor dulu.

**K19. Obat Malam 3 dan penutupan malam.**
Sama dengan K11 di Malam 2: desain 4.3 menutup malam setelah semua tujuan wajib selesai, dan obat bukan tujuan wajib. Pemain cepat bisa menutup Malam 3 sebelum 21.00 dan kehilangan +2 tanpa teguran.

**K20. Ritual Penangkal wajib di Malam 3.**

using System;

namespace TheSending.Core
{
    public enum HasilCabut { Ditolak, Benar, Salah }

    // Malam 3 (Game Story): mengetuk empat saka guru, lalu mencabut tujuh paku berukir nama hari dari saka yang benar.
    // Urutan mulai hari malam ini (Kamis malam = malam Jumat), lalu hari-hari berikutnya. Salah urutan: Kondisi Ibu -5,
    // kemajuan tetap; Sosok Santet yang muncul diurus Runtime. Kemajuan disimpan di GameState supaya selamat dari checkpoint.
    public static class TujuhPaku
    {
        public const int Jumlah = 7;
        public const int SakaBenar = 3;   // saka timur laut ruang tengah; nomor saka 0..3 dipasang PembuatMalam3
        public const int MalamPaku = 3;

        static Hari[] Urutan => KalenderJawa.UrutanPaku(MalamPaku);

        // true = saka berbunyi berongga; paku di baliknya ditemukan (M2 otomatis masuk Papan Bukti, desain 4.7).
        public static bool Ketuk(GameState s, int saka)
        {
            if (saka < 0 || saka > 3) throw new ArgumentOutOfRangeException(nameof(saka), saka, "Saka guru harus 0..3.");
            if (saka != SakaBenar) return false;
            MediaSantet.Temukan(s, Kode.M2);
            return true;
        }

        public static bool Selesai(GameState s) => s.PakuDicabut >= Jumlah;

        public static bool SudahDicabut(GameState s, Hari hari) => Array.IndexOf(Urutan, hari) < s.PakuDicabut;

        public static HasilCabut Cabut(GameState s, Hari hari)
        {
            if (!s.MediaDitemukan[Kode.M2] || Selesai(s) || SudahDicabut(s, hari)) return HasilCabut.Ditolak;
            if (Urutan[s.PakuDicabut] != hari)
            {
                KondisiIbu.Ubah(s, KondisiIbu.SalahUrutanPaku);
                return HasilCabut.Salah;
            }
            s.PakuDicabut++;
            if (Selesai(s)) TujuanMalam.Selesaikan(s, TujuanMalam.CabutPaku);
            return HasilCabut.Benar;
        }
    }
}

        public bool MenungguKubur => ritual != null && ritual.Kemajuan == LangkahDiAnglo;
        public bool ApiMenyala => ritual != null && ritual.Kemajuan >= LangkahApi;
        public int Media { get; private set; } = -1;

        void Awake()
        {
            var akar = UiPabrik.BuatCanvas("Ritual", 16).transform;
            akar.SetParent(transform, false);
            var latar = UiPabrik.BuatPanel(akar, "Latar", new Color(0.05f, 0.04f, 0.03f, 0.96f), new Vector2(0.2f, 0.15f), new Vector2(0.8f, 0.85f));

            UiPabrik.BuatTeks(latar.transform, "Judul", 30, TextAnchor.UpperLeft, new Vector2(0.04f, 0.88f), new Vector2(0.96f, 0.97f)).text =

            pesan = UiPabrik.BuatTeks(latar.transform, "Pesan", 24, TextAnchor.UpperLeft, new Vector2(0.04f, 0.03f), new Vector2(0.96f, 0.2f));
            panel.SetActive(false);
        }

        public void Buka()
        {
            var gm = GameManager.Instance;
            if (Terbuka || gm == null || gm.Dijeda || MenungguKubur) return;
            frameBuka = Time.frameCount;   // tombol E yang membuka panel tidak ikut terbaca
            pesan.text = "[Esc] tutup";
            panel.SetActive(true);
            gm.Jeda(true);
            Gambar(gm.State);
        }

        void Update()
        {
            if (!Terbuka || Time.frameCount == frameBuka) return;
            var gm = GameManager.Instance;
            if (gm == null) return;
            var k = gm.Kontrol;
            if (k.JedaMenu.WasPressedThisFrame())
            {
                Tutup();
                return;
            }
            int jumlah = ritual == null ? pilihanMedia.Count : Pilihan.Length;
            for (int i = 0; i < jumlah && i < k.PilihanAngka.Length; i++)
            {
                if (!k.PilihanAngka[i].WasPressedThisFrame()) continue;
                if (ritual == null) MulaiRitual(gm.State, pilihanMedia[i]);
                else Lakukan(gm.State, Pilihan[i].langkah);
                return;
            }
        }

        void MulaiRitual(GameState s, int media)
        {
            ritual = new RitualPenangkal(s, media);
            Media = media;
            pesan.text = PetunjukLangkah;
            Gambar(s);
        }

        void Lakukan(GameState s, LangkahRitual langkah)
        {
            if (!ritual.Lakukan(langkah))
            {
                pesan.text = "Ritual gagal: urutannya salah. Ulangi dari langkah pertama.\n" + PetunjukLangkah;
                Gambar(s);
                return;
            }
            pesan.text = PetunjukLangkah;
            if (!MenungguKubur)
            {
                Gambar(s);
                return;
            }
            Tutup();
            hud.Tampilkan("Media sudah menjadi abu. Kubur abunya di pekarangan belakang.");
        }

        // Dipanggil KuburAbu di pekarangan: langkah keenam. Core menetralkan media (+8) dan menandai RitualPertama.
        public bool Kubur()
        {
            if (!MenungguKubur) return false;
            ritual.Lakukan(LangkahRitual.KuburAbu);
            ritual = null;
            Media = -1;
            return true;
        }

        void Gambar(GameState s)
        {
            var sb = new StringBuilder();
            pilihanMedia.Clear();
            if (ritual != null)
            {
                sb.AppendLine($"Media di atas anglo: {NamaMedia[Media]}");
                sb.AppendLine($"Langkah selesai: {ritual.Kemajuan} dari {LangkahDiAnglo}\n");
                for (int i = 0; i < Pilihan.Length; i++) sb.AppendLine($"{i + 1}. {Pilihan[i].teks}");
            }
            else if (!s.RitualDiketahui)
                sb.AppendLine("Raka belum tahu cara menetralkan media santet.");
            else if (!RitualPenangkal.BahanLengkap(s))
            {
                sb.AppendLine("Bahan belum lengkap:");
                foreach (var (bahan, teks) in TempatBahan)
                    if (!s.BahanRitual[(int)bahan]) sb.AppendLine("- " + teks);
            }
            else
            {
                // shortcut: paling banyak 5 media tampil (tombol 1-5); Malam 3 paling banyak dua (M1, M2). Tambah halaman jika Malam 5+ butuh lebih.
                for (int m = 0; m < Kode.JumlahMedia && pilihanMedia.Count < LangkahDiAnglo; m++)
                    if (RitualPenangkal.BisaMulai(s, m)) pilihanMedia.Add(m);
                if (pilihanMedia.Count == 0) sb.AppendLine("Tidak ada media yang bisa dinetralkan sekarang.");
                else
                {
                    sb.AppendLine("Media yang diletakkan di anglo:");
                    for (int i = 0; i < pilihanMedia.Count; i++) sb.AppendLine($"{i + 1}. {NamaMedia[pilihanMedia[i]]}");
                    pesan.text = PetunjukMedia;
                }
            }
            isi.text = sb.ToString();
        }

        // Panel dimatikan atau dihancurkan saat terbuka (misalnya ganti scene): lepaskan jeda.
        void OnDisable() => Tutup();

        void Tutup()
        {
            if (!Terbuka) return;
            if (ritual != null && !MenungguKubur)
            {
                ritual = null;   // belum menjadi abu: batal, mulai lagi dari awal saat panel dibuka lagi
                Media = -1;
            }
            panel.SetActive(false);
            if (GameManager.Instance != null) GameManager.Instance.Jeda(false);
        }
    }
}

    // Guncangan pengganti animasi tokoh (Laras gemetar, Ibu menjerit) sampai model beranimasi datang.
    // Waktu tanpa skala, karena adegan menjeda gim.
    public static class Guncang
    {
        public static IEnumerator Posisi(Transform t, float lama, float kuat)
        {
            var awal = t.localPosition;
            for (float w = 0f; w < lama; w += Time.unscaledDeltaTime)
            {
                t.localPosition = awal + new Vector3(Random.Range(-kuat, kuat), 0f, Random.Range(-kuat, kuat));
                yield return null;
            }
            t.localPosition = awal;
        }
    }
}

        {
            if (!berjalan) return;
            if (hasil == HasilCabut.Benar)
            {
                suaraCabut.Putar();
                return;
            }
            var gm = GameManager.Instance;
            hud.Tampilkan("Paku itu tidak mau lepas. Ibu mengerang dari kamarnya.");
            if (KeMenuJikaEnding(gm)) return;
            // K21-A: checkpoint sesudah penalti dan sebelum Sosok muncul (desain 2.6), supaya penalti dan paku yang sudah
            // dicabut tidak hilang saat tertangkap.
            gm.SimpanCheckpoint();
            if (!sosokBerjalan) SosokMuncul();
        }

        void SosokMuncul()
        {
            sosokBerjalan = true;
            sisaSosok = LamaSosok;
            suaraStinger.Putar();
            sosok.transform.SetPositionAndRotation(titikMunculSosok.position, titikMunculSosok.rotation);
            sosok.gameObject.SetActive(true);   // SosokSantet.OnEnable menaruhnya di NavMesh dan mulai berpatroli
            musikTegang.Putar();
            hud.Tampilkan("Gemerincing paku terdengar dari dapur. Bersembunyi (E di lemari) dan tahan napas (Spasi).");
        }

        // Sosok pergi setelah LamaSosok detik waktu gim (berhenti saat jeda). Detak jantung selama Raka bersembunyi.
        void AturSosok()
        {
            if (pemain.Bersembunyi != detakBerbunyi)
            {
                detakBerbunyi = pemain.Bersembunyi;
                if (detakBerbunyi) suaraDetak.Putar();
                else suaraDetak.Hentikan();
            }
            sisaSosok -= Time.deltaTime;
            if (sisaSosok > 0f) return;
            sosokBerjalan = false;
            sosok.gameObject.SetActive(false);
            musikTegang.Hentikan();
            suaraDetak.Hentikan();
            detakBerbunyi = false;
            hud.Tampilkan("Gemerincing paku itu menjauh, lalu hilang.");
        }

        void SaatTertangkap()
        {
            if (!sosokBerjalan) return;
            sosokBerjalan = false;
            StartCoroutine(Tertangkap());
        }

        // Desain 4.2: muat checkpoint (salah cabut terakhir, K21-A), lalu Kondisi Ibu -5. Scene dimuat ulang dari state itu.
        IEnumerator Tertangkap()
        {
            sibuk = true;
            var gm = GameManager.Instance;
            adegan.Mulai();
            musikTegang.Hentikan();
            suaraDetak.Hentikan();
            suaraStinger.Putar();
            yield return kartu.StartCoroutine(kartu.Tampilkan("", "Sosok itu menemukan Raka.", 2f));
            yield return kartu.StartCoroutine(kartu.KeHitam());
            gm.Tertangkap();
            // Jeda dilepas KameraAdegan.OnDisable saat scene dibongkar.
            gm.MuatScene(gm.State.Ending != Ending.Belum ? GameManager.SceneMenuUtama : gm.SceneUntukState);
        }

        // Game Story Malam 3 butir 7: Raka pergi ke rumah Bu Sumi (K17-A: pintu depan langsung memuat scene-nya).
        void SaatPintuDepan()
        {
            if (!berjalan || sibuk) return;
            var s = State;
            if (!TujuanMalam.Sudah(s, TujuanMalam.CabutPaku))
                hud.Tampilkan("Raka tidak bisa pergi selama Ibu terus menjerit.");
            else if (TujuanMalam.Sudah(s, TujuanMalam.KunjungiSumi))
                hud.Tampilkan("Sudah larut. Raka tidak keluar lagi malam ini.");
            else if (sosokBerjalan)
                hud.Tampilkan("Gemerincing paku masih terdengar. Jangan keluar sekarang.");
            else
                StartCoroutine(KeRumahBuSumi());
        }

        IEnumerator KeRumahBuSumi()
        {
            sibuk = true;
            adegan.Mulai();
            suaraPintuDepan.Putar();
            yield return kartu.StartCoroutine(kartu.KeHitam());
            GameManager.Instance.MuatScene(PetaScene.RumahBuSumi);   // jeda dilepas KameraAdegan.OnDisable saat scene dibongkar
        }

        // Ending sebelum Fase 7: kembali ke menu utama (layar ending dibuat di Fase 7).
        bool KeMenuJikaEnding(GameManager gm)
        {
            if (gm.State.Ending == Ending.Belum) return false;
            Debug.LogWarning("Ending tercapai di Malam 3; layar ending dibuat di Fase 7.", this);
            gm.MuatScene(GameManager.SceneMenuUtama);
            return true;
        }

        IEnumerator GantiMalam(GameState s)
        {
            gantiDimulai = true;
            sibuk = true;
            var gm = GameManager.Instance;
            bool dimuat = false;
            adegan.Mulai();
            try
            {
                yield return kartu.StartCoroutine(kartu.KeHitam());
                PergantianMalam.Lanjut(s);        // Malam 4, Kondisi Ibu -12
                if (KeMenuJikaEnding(gm))         // catatan 0B: -12 bisa langsung memicu ending
                {
                    dimuat = true;
                    yield break;
                }
                gm.SimpanCheckpoint();            // checkpoint awal Malam 4
                // Fase 4 mengganti bagian di bawah ini dengan gm.MuatScene(gm.SceneUntukState) untuk sutradara Malam 4.
                yield return kartu.StartCoroutine(kartu.Tampilkan(
                    "Malam 4: Rambut di Dasar Sumur",
                    KalenderJawa.NamaMalam(4) + "\n\n" + RingkasanMalam4 + "\n\n(Bersambung. Malam 4 dibuat di Fase 4.)", 8f));
                yield return kartu.StartCoroutine(kartu.KeHitam());
                gm.MuatScene(GameManager.SceneMenuUtama);
                dimuat = true;
            }
            finally { if (!dimuat) adegan.Selesai(); }   // jeda dilepas KameraAdegan.OnDisable saat scene dibongkar
        }
    }
}

using System;
using System.Collections;
using TheSending.Core;
using UnityEngine;

namespace TheSending.Runtime
{
    // Sutradara rumah Bu Sumi pada Malam 3 (Game Story Malam 3 butir 7-8, Kepercayaan 6.4, K17-A dan K23-A).
    // Bu Sumi dingin di ambang pintu; pilihan dialog: minta maaf (+1), menuduh (-1, pintu dibanting sampai malam
    // berikutnya), atau menawarkan bantuan. Teplok di teras dan sumur di halaman (+1 setelah keduanya, lapor ke Bu Sumi).
    // Kepercayaan minimal 1: cerita tiga tahun lalu dan Ritual Penangkal di bale-bale. Gerbang kembali ke rumah keluarga.
    // Tidak ada checkpoint di sini; kemajuan kunjungan disimpan di GameState lewat efek dialog.
    public class AlurRumahBuSumi : MonoBehaviour
    {
        const float LamaKerja = 2.5f;

        [SerializeField] KameraAdegan adegan;
        [SerializeField] KartuTeks kartu;
        [SerializeField] PanelDialog dialog;
        [SerializeField] Hud hud;
        [SerializeField] PemainGerak pemain;
        [SerializeField] DataDialog dialogPintu, dialogMenunggu, dialogTerimaKasih, dialogPamit, dialogCerita;
        [SerializeField] InteraktifAlur buSumi, teplok, sumur, gerbang;
        [SerializeField] GameObject pintu, cahayaTeplok;
        [SerializeField] Transform titikMulai, titikBale, titikSumiBale, bidikBale;
        [SerializeField] Suara suaraBanting, suaraTimba, suaraGerbang;

            sumur.Ditekan -= SaatSumur;

        {

                return;
            }
            berjalan = true;

            StartCoroutine(Datang(s));
        }

        // Pintu terbuka: Bu Sumi berdiri di ambangnya. Tertutup (setelah dituduh): pintu ada, Bu Sumi di dalam.
        void AturPintu(GameState s)
        {
            bool terbuka = KepercayaanSumi.PintuTerbuka(s);

        }

        IEnumerator Datang(GameState s)
        {
            sibuk = true;
            yield return kartu.StartCoroutine(kartu.DariHitam());
            hud.Tampilkan(KepercayaanSumi.PintuTerbuka(s)

            else if (teplokBeres && airBeres) d = dialogTerimaKasih;

            sibuk = true;
            yield return dialog.MulaiDanTunggu(d);
            var s = State;
            if (!KepercayaanSumi.PintuTerbuka(s))
            {

        {

            if (!TujuanMalam.Sudah(s, TujuanMalam.KunjungiSumi))

        }

        // R4: kunjungan sekali per malam. Pulang sebelum selesai membantu diberi peringatan satu kali.
        void SaatGerbang()
        {
            if (sibuk) return;
            if (berjalan)
            {
                var s = State;
                if (!TujuanMalam.Sudah(s, TujuanMalam.KunjungiSumi))
                {

            }
            StartCoroutine(Pulang());
        }

        IEnumerator Pulang()
        {
            sibuk = true;
            adegan.Mulai();
            suaraGerbang.Putar();
            yield return kartu.StartCoroutine(kartu.KeHitam());
            GameManager.Instance.MuatScene(PetaScene.RumahKeluarga);   // jeda dilepas KameraAdegan.OnDisable saat scene dibongkar
        }
    }
